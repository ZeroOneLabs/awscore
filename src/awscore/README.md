# awscore

**AWS Core Utilities** – data platform backbone.

Shared library for:
- S3, Secrets Manager, Lambda + Layers
- Postgres/RDS (pooling, IAM, singleton)
- CSV/XML validation (XSD via lxml)
- Structured JSON logging (CloudWatch-ready)
- AutoLogger + respondent context
